# Lab 06 — Compromised Endpoint Incident Response

**Status: Execution-ready.**

## Objective
Demonstrate Windows endpoint triage and incident-response reasoning in a controlled lab.

## Investigation Workflow

```text
Alert -> Triage -> Evidence Preservation -> Process/Log Review
      -> Scope -> Containment -> Eradication -> Recovery -> Lessons Learned
```

## Evidence Sources

- Windows Security logs;
- PowerShell logs;
- process creation telemetry;
- scheduled tasks / services;
- user and privilege changes;
- network connections;
- file-system artifacts.

## Deliverables
Incident timeline, analyst notes, indicators and affected assets, containment decisions, remediation plan, lessons learned, and detection improvements.
