# Lab 05 — Network Traffic Investigation

**Status: Execution-ready.**

## Objective
Analyze packet captures and network telemetry to reconstruct suspicious activity and produce an analyst-quality investigation.

## Analysis Areas

- DNS resolution;
- HTTP requests and responses;
- TLS metadata;
- source/destination relationships;
- unusual ports and protocols;
- beacon-like behavior;
- failed and successful connection sequences;
- suspicious downloads or transfers;
- timeline reconstruction.

## Tooling

- Wireshark
- tshark where useful
- TCP/IP analysis
- enrichment using documented public sources when permitted

## Deliverables
Case summary, PCAP provenance, filters used, suspicious flows, timeline, indicators, ATT&CK context, analyst disposition, and containment/remediation recommendations.
