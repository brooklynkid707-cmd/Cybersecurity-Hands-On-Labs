# Lab 08 — Security Automation & Engineering Capstone

**Status: Execution-ready.**

## Objective
Combine detection, enrichment, evidence handling, and reporting into a repeatable security-engineering workflow.

## Candidate Automation Components

- Python log parsing;
- PowerShell evidence collection;
- structured IOC extraction;
- event normalization;
- simple enrichment through approved APIs;
- case/timeline generation;
- report generation;
- test fixtures and validation checks.

## Engineering Requirements

- clear inputs and outputs;
- configuration separated from code;
- error handling;
- repeatable tests;
- sample/synthetic data;
- no hard-coded secrets;
- README with architecture and usage;
- security limitations documented.

## Capstone Goal
Show the ability to move from a single analyst task to a reliable, documented workflow that another analyst could reproduce.
